JavaScript API

Use the same mapping function in Node.js and browser modules. The package root exposes v2.

Install and import

npm install map-json-by-json
import { mapJson, meta } from "map-json-by-json";
// Or import the versioned entry point:
import mapJsonV2 from "map-json-by-json/v2";

Call signature

mapJson(template, source)
mapJson({ inTemplate: template, inSource: source })

The result follows the template shape. A source array maps to an array of results. Missing source fields are omitted from the mapped object.

Template rules

  • A string selects a source property or dot path.
  • { $from: "PATH", ...fields } maps a source collection recursively.
  • { $value: value } inserts a constant.
  • A function rule receives the current source item and returns a computed value.
  • Nested objects reshape fields from the same source object.

Example

const template = {
  name: "CUSTOMER.NAME",
  total: "TOTAL",
  lines: {
    $from: "LINES",
    label: "ITEM",
    amount: "AMOUNT"
  }
};

const result = mapJson(template, source);
