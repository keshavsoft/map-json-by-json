Command line

Transform JSON files or pipe source JSON through the v2 mapper.

Run with npx

npx map-json-by-json --template template.json --input source.json

This repository includes a ready-to-run example:

node bin/map-json-by-json.js --template examples/order-template.json --input examples/order-source.json

Install the package locally to use the command repeatedly:

npm install map-json-by-json
npx map-json-by-json --template template.json --input source.json --output result.json

Options

  • --template, -t: path to a JSON template file.
  • --input, -i: source JSON file, or - to read standard input.
  • --output, -o: write formatted JSON to a file. Defaults to standard output.
  • --help, -h: show usage.
  • --version, -v: show the engine version.

Pipes

cat source.json | npx map-json-by-json --template template.json --input -

Templates are JSON, so they support string paths, $from, and $value. Use the JavaScript API when a template needs function transformers.
