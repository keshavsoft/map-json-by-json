Data examples

Keep templates focused on the output contract. Map only the source values the consumer needs.

Input data

{
  "ORDER_NO": 501,
  "CUSTOMER": { "NAME": "Acme Global" },
  "LINES": [
    { "SKU": "Cable", "AMOUNT": 45.5 },
    { "SKU": "Connector", "AMOUNT": 12 }
  ]
}

Template

{
  "orderId": "ORDER_NO",
  "customerName": "CUSTOMER.NAME",
  "items": {
    "$from": "LINES",
    "name": "SKU",
    "amount": "AMOUNT"
  }
}

Mapped output

{
  "orderId": 501,
  "customerName": "Acme Global",
  "items": [
    { "name": "Cable", "amount": 45.5 },
    { "name": "Connector", "amount": 12 }
  ]
}

Try the interactive playground to edit templates and source data in your browser.

The same sample is stored in examples/order-template.json and examples/order-source.json for CLI testing.
