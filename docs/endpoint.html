HTTP endpoint example

The package is a mapper library. This optional Node.js example wraps it in a small local HTTP endpoint.

Start the example server

node examples/http-server.js
# Listening on http://localhost:3000

POST /map

curl -X POST http://localhost:3000/map \
  -H "Content-Type: application/json" \
  -d '{
    "template": { "label": "NAME", "price": "PRICE" },
    "source": { "NAME": "Cable", "PRICE": 12.5 }
  }'

Response:

{ "result": { "label": "Cable", "price": 12.5 } }

Request limits

The sample accepts JSON POST requests up to 1 MiB and returns JSON errors for invalid input. Add authentication, authorization, rate limiting, and application-specific validation before exposing a service publicly.
