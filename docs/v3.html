v3 strict mapper

Pass a JSON mapping template first and source JSON second. V3 reads both inputs without changing them and returns newly created JSON.

Import v3

npm install map-json-by-json
import { mapJson } from "map-json-by-json/v3";

const template = {
  name: "person.fullName",
  city: "person.address.city",
  tags: { $from: "labels", value: "text" },
  active: { $value: true }
};

const source = {
  person: { fullName: "Asha Rao", address: { city: "Pune" } },
  labels: [{ text: "customer" }, { text: "verified" }]
};

const result = mapJson(template, source);
// { name: "Asha Rao", city: "Pune", tags: [{ value: "customer" }, { value: "verified" }], active: true }

Strict behavior

  • The first argument is a plain JSON mapping object. String values name paths in the second argument.
  • The second argument is a JSON object or an array of JSON objects.
  • Input objects are never changed. The returned object and nested values are new copies.
  • Every requested source path must exist. A missing path throws an error that names the template field.
  • Inputs must contain JSON values only. Functions, circular references, sparse arrays, and non-plain objects are rejected.
  • Use { "$value": "literal" } when a string should be returned as a literal.

Mapping a collection

const template = {
  invoiceNo: "number",
  lines: {
    $from: "items",
    product: "name",
    quantity: "qty"
  }
};

const result = mapJson(template, {
  number: "INV-10",
  items: [
    { name: "Cable", qty: 3 },
    { name: "Adapter", qty: 1 }
  ]
});
