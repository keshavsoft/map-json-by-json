Install and use

Choose a package import for an application, npx for a one-off command, or a CDN module for a browser page.

npm package import (v2)

npm install map-json-by-json
import { mapJson } from "map-json-by-json";

const template = { displayName: "customer.name", total: "amount" };
const source = { customer: { name: "Asha" }, amount: 42 };
const result = mapJson(template, source);
// { displayName: "Asha", total: 42 }

The package root remains v2. Import v3 explicitly with map-json-by-json/v3.

One-off run with npx

Put the mapping template and input data in JSON files, then run:

npx map-json-by-json --template template.json --input source.json --output result.json

Omit --output to print the result. Use --input - to read JSON from standard input.

Install and run the CLI

Install the package globally if you use the command in multiple projects:

npm install --global map-json-by-json
map-json-by-json --template template.json --input source.json --output result.json

Or add it to one project and invoke it through npm:

npm install --save-dev map-json-by-json
npm exec -- map-json-by-json --template template.json --input source.json

The CLI accepts JSON templates with string paths, $from, and $value. Use the JavaScript API for function-based v2 rules.

Use from a browser with a CDN

Pin the package version so your page keeps a predictable release:

<script type="module">
  import { mapJson } from "https://cdn.jsdelivr.net/npm/map-json-by-json@2.0.0/src/v2/browser.js";

  const result = mapJson({ label: "name" }, { name: "Cable" });
  document.querySelector("#result").textContent = JSON.stringify(result);
</script>

After release 2.1.0 is published, the strict v3 browser module can be imported from https://cdn.jsdelivr.net/npm/map-json-by-json@2.1.0/src/v3/index.js.

Build the documentation app

npm install
npm run docs:build

Vite writes the v2 playground build to docs/dist/v2. Run npm run docs:dev for Vite's local server, or npm run docs:serve to serve the working tree's local v2 module.
