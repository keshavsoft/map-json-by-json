Browser and CDN

The v2 browser entry is an ES module and has no Node.js runtime dependency.

Install in a browser app

npm install map-json-by-json
import { mapJson } from "map-json-by-json/browser";

const result = mapJson(template, source);

Use from a pinned CDN release

<script type="module">
  import { mapJson } from "https://cdn.jsdelivr.net/npm/map-json-by-json@2.0.0/src/v2/browser.js";

  const result = mapJson({ name: "NAME" }, { NAME: "Cable" });
  document.querySelector("#result").textContent = JSON.stringify(result);
</script>

Pin a release version in production pages so an update cannot change behavior without a deployment.

Global registration

Module imports are side-effect free. For legacy integrations that expect globalThis.ks, import the explicit map-json-by-json/global entry.
